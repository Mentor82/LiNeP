# LiNeP legal and licensing documents

This directory is the legal-documentation index for LiNeP and LiNeP-SL:

- [`LICENSING_POLICY.md`](LICENSING_POLICY.md) defines the Apache-2.0 scope,
  independent-implementation policy, generated-artifact policy, contribution
  rule, and release requirements.
- [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) inventories bundled and
  non-bundled dependencies and records the licenses and source references that
  apply to them.
- [`TRADEMARK_POLICY.md`](TRADEMARK_POLICY.md) keeps name and logo use separate
  from copyright and patent permissions.
- The repository root [`LICENSE`](../../LICENSE) contains Apache-2.0, and the
  root [`NOTICE`](../../NOTICE) identifies the project and third-party notice
  location.

These documents describe the project's licensing intent and distribution
practice. They are not legal advice. A distributor remains responsible for
reviewing the laws and third-party licenses applicable to its own release.
