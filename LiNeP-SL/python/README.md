# linep-sl

Python bindings for the LiNeP-SL security layers.

LiNeP-SL protects LiNeP communication with authentication, cryptographic
identity, authorization, replay protection, policy, audit, and federation
semantics. It remains separate from the LiNeP transport/runtime protocol.
