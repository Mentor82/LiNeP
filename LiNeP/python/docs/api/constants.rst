linep.constants
===============

This module provides :class:`enum.IntEnum` and :class:`enum.IntFlag` types
that mirror all named constants from the LiNeP C protocol.  Using Python
enums instead of bare integers improves readability and enables IDE
auto-completion while remaining fully interchangeable with plain ``int``
values at the cffi boundary.
